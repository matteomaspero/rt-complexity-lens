# Lovable Context

Educational/research tool — not clinically validated.

## 3D Treatment Room (Viewer)
- Schematic linac (gantry, collimator, jaws, per-leaf MLC, couch, head-first supine patient) driven by the selected beam's control points.
- Gantry travel is bounded to −185°…+185° (IEC 61217 signed); arcs are unwrapped with their CW/CCW direction so the gantry reverses through 0° instead of rotating under the couch. A badge warns if a plan would exceed the travel.
- Shortcuts (panel focused): Space play/pause · ←/→ CP (Shift ×10) · Home/End · G/C/T ±1° gantry/collimator/couch (Shift = −, Alt ×10) · L MLC plan/open/closed · 1/2/3/R camera · ? help. "Manual" detaches from the plan; "Follow plan" returns.
